#  FitLog — Workout Library

FitLog is a modern and responsive workout library web application designed to help users explore exercises, create a daily workout plan, and save workouts for later.

##  Technologies Used

* **Next.js** — React framework for the application
* **React.js** — Building reusable UI components
* **Tailwind CSS** — Styling and responsive design
* **DaisyUI** — UI components
* **React Toastify** — Notifications and feedback
* **Context API** — Managing workout plan and saved workout state
* **REST API** — Fetching workout data

##  Key Features

### 1.  Workout Library

Browse a collection of workouts with information such as muscle groups, equipment, difficulty, duration, calories, and ratings.

### 2. Workout Details

View detailed information about each workout, including sets, reps, instructions, equipment, and workout statistics.

### 3.  Daily Workout Plan

Add exercises to your **Today's Plan** and manage the workouts you want to complete.

### 4.  Save for Later

Save your favorite workouts and access them later from the **Saved** section.

### 5.  Responsive Design

FitLog is designed to work smoothly across mobile, tablet, and desktop devices with a clean dark gym-focused interface.

## Project Goal

The goal of FitLog is to provide a simple and focused workout experience where users can discover exercises, organize their workouts, and keep track of their training plans.
